# DBMS SQL Plus

A collection of Database Management System (DBMS) practicals and SQL queries implemented using Oracle SQL*Plus.

## 📌 About the Repository

This repository contains SQL programs and practical implementations related to Database Management Systems. It focuses on understanding relational databases, SQL commands, database operations, and PL/SQL concepts through hands-on practice.

The repository is developed as part of the academic DBMS coursework to gain practical experience in database creation, manipulation, querying, and management using SQL*Plus.

## 🎯 Objectives

- Understand fundamental DBMS concepts.
- Learn SQL syntax and database operations.
- Create and manage relational database tables.
- Perform data insertion, updating, deletion, and retrieval.
- Implement different types of SQL queries.
- Understand constraints and relationships between tables.
- Practice database operations using Oracle SQL*Plus.
- Develop practical database management skills.

## 📚 Concepts Covered

- **DDL (Data Definition Language):** CREATE, ALTER, DROP, TRUNCATE.
- **DML (Data Manipulation Language):** INSERT, UPDATE, DELETE.
- **DQL (Data Query Language):** SELECT.
- **DCL (Data Control Language):** GRANT, REVOKE.
- **TCL (Transaction Control Language):** COMMIT, ROLLBACK, SAVEPOINT.
- Primary Key and Foreign Key Constraints.
- Aggregate Functions.
- GROUP BY and HAVING.
- Joins and Subqueries.
- Views and Database Operations.
- PL/SQL Programming.

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- Oracle Database (XE or another compatible version).
- Oracle SQL*Plus or Oracle SQL Developer.
- Visual Studio Code (optional).

### 1. Clone the Repository

```bash
git clone https://github.com/arjunabalpande06/DBMS_SQL_Plus.git
```

### 2. Navigate to the Project Directory

```bash
cd DBMS_SQL_Plus
```

### 3. Connect to Oracle SQL*Plus

Open the terminal and execute:

```bash
sqlplus username/password@database
```

Replace the username, password, and database connection details with your own credentials.

### 4. Execute SQL Files

Run an SQL file using:

```sql
@filename.sql
```

For PL/SQL programs, enable output before execution:

```sql
SET SERVEROUTPUT ON;
```

### 5. View the Output

Execute the SQL statements and observe the results in SQL*Plus or SQL Developer.
